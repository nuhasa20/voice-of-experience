Voice of Experience (صوت الخبرة) — App Map

A compact architectural guide to the proof-of-concept codebase. Trace how spoken troubleshooting knowledge flows from audio capture to quote-verified diagnostic cards and threshold-bounded search.

1. Architecture in Plain Language

The system consists of three modular layers running locally without cloud lock-in:

  • Frontend SPA (static/): A single-page interface with an accessible search hero, an interactive suggestions dropdown, and a 4-step diagnostic wizard (Microphone recording via MediaRecorder, verbatim transcript review with live [unclear] counter, 5-field preview, and expert approval).
  • Backend Engine (server/): A lightweight FastAPI server that transcribes audio via a 3-tier cascade, normalizes Libyan Arabic dialect text, enforces exact substring quote verification, and ranks cards using character n-gram cosine similarity.
  • Local Storage (data/ & audio/): A private SQLite database storing diagnostic cards and SHA-256 keyed cache tables, alongside an audio directory holding OGG Opus voice notes.

3. Reference Code Route (Key Locations)

Follow the exact code execution path for the system's core capabilities:

Stop 1: Verbatim Quote Verification Guard
server/extractor.py → extract_card_fields()

Normalizes Arabic text (removing diacritics and unifying Alef/Yaa variants) and executes deterministic substring checks. If an AI model attempts to paraphrase rather than quote directly, or if the quote contains [unclear], the field is rejected with "Could not be verified – please edit".

Stop 2: Character N-Gram Retrieval & Threshold Gate
server/search.py → search_cards()

Vectorizes queries into character 3-gram to 5-gram TF-IDF representations (analyzer="char_wb", ngram_range=(3, 5)). Computes cosine similarity against all stored cards. If the top score is below SEARCH_THRESHOLD (0.19), it suppresses ungrounded output and triggers the fallback contract.

Stop 3: Client Controller & Suggestions Panel
static/js/search.js → class SearchController

Binds keyboard navigation (Arrow keys, Enter, Escape), manages the detached floating suggestions panel with example chips, and renders result cards with audio playback and expandable diagnostic breakdowns.

4. To Change This, Start Here

Adjust "I Don't Know" Sensitivity

Edit SEARCH_THRESHOLD in .env or server/config.py. Increasing towards 0.25 makes the system stricter; decreasing towards 0.15 allows broader matches.

Add Dialect Synonyms & Aliases

Update ALIAS_DICT in server/search.py to add domain terms (e.g. mapping "طلمبة" to "مضخة pump").

Configure STT Fallback Cascade

Change STT_PRIMARY_MODEL or STT_SECONDARY_MODEL in .env to switch between Gemini Flash tiers or Groq Whisper.

Modify Diagnostic Fields Schema

Adjust EXTRACTION_PROMPT and field definitions in server/extractor.py.

5. A Practice to Reuse

Architectural Pattern: Deterministic Verifiers as Safety Wrappers Around LLMs

In mission-critical industrial applications, generative language models should not be trusted to self-verify their own facts. Voice of Experience demonstrates a reusable pattern:

  • Use the LLM for translation and semantic extraction.
  • Use deterministic, non-LLM code (Python string normalization, substring validation, and TF-IDF similarity math) to verify outputs and enforce boundaries.
  • Enforce a human-in-the-loop approval gate before writes to the production knowledge base.
